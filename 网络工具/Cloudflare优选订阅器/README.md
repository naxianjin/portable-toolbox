# Cloudflare 优选 IP 订阅器

为你已有的 **VLESS + WebSocket + TLS** 节点筛选 Cloudflare 入口，再生成客户端订阅。本机 CFST 测量延迟与下载速度，Xray 复测完整连接；网页回填 15 个入口，核对后发布前 10 条。

[下载 Windows x64 便携包](https://github.com/naxianjin/portable-toolbox/releases/download/cfsub-v1.3.7/Cloudflare-IP-Subscription-Windows-x64.zip) · [发布说明与 SHA-256](https://github.com/naxianjin/portable-toolbox/releases/tag/cfsub-v1.3.7) · [PDF 使用指南](使用指南.pdf) · [在线订阅器](https://cloudflaresub.naxianjin8.workers.dev/)

当前版本 **v1.3.7**，支持 Windows 10 / 11 x64，建议使用 Edge 或 Chrome。包内已有 Node、CFST、Xray、IP 列表和必要运行库，无需安装开发环境、管理员权限或 Cloudflare 账号。

程序不提供 VPS 或原始节点。你需要一条自己能够连接的 `vless://` 分享链接，以及支持 VLESS 的代理客户端。GitHub 的 **Code → Download ZIP** 只下载说明文件；程序请使用上方便携包链接。

## 第一次使用

1. **完整解压**便携包到可写文件夹，保留整个“程序”目录，不要在压缩软件中直接运行。
2. 首次双击 `启用网页测速.cmd`。以后打开在线订阅器，点击“唤起测速助手”并允许打开本机应用；也可双击 `打开订阅器.cmd` 启动并绑定本机空间。
3. 浏览器提示访问本地网络时允许该请求。先点“检查连接”，确认助手版本和测速文件就绪。
4. 在“原始节点”粘贴完整分享链接，点击“一键测速并填入”，等待测速与完整连接复测。通常填写一条节点即可，完整复测使用第 1 条。
5. 点击“预览并更新订阅”，核对并确认发布。到“订阅结果”复制对应格式的地址或扫码导入客户端。

**网页测速只回填草稿，确认发布后才更新线上订阅。** v2rayN / v2rayNG 使用 Raw，支持 VLESS 的 Clash / Mihomo 使用 Clash 格式，Shadowrocket 使用对应入口。纯 VLESS 不提供 Surge 导出。

首次启用后，电脑重启也可从网页唤起助手。移动目录后需重新启用；多个目录共用最后注册的入口。浏览器本身无法执行本机测速，运行时仍需要便携包中的助手。

## 测速规则

- 网页先测试 30 个低延迟候选，再筛选 15 个入口。默认要求无探测丢包、连接延迟不超过 200 ms、下载速度至少 0.1 MB/s。
- Xray 默认对每个入口发起 3 次完整 HTTPS 请求。本轮通过不足 10 个时，重新测速并复测同一场景的上次入口，按本轮速度只补缺口：9 个通过补 1 个，8 个通过补 2 个。
- 最终顺序为本轮新通过入口、旧入口补位、本轮其他候选，前 10 条均通过复测。重复、异端口、未达速度门槛或复测失败的旧入口不会加入。
- 自动测速未找齐 15 条入口，或新旧入口合计仍不足 10 条通过时，不发布替换结果。测速与复测支持 IPv4、IPv6 和混合模式。

CFST 的延迟、下载速度与完整 HTTPS 请求耗时是不同指标，实际代理下载速度可在客户端另测。测速前确认 TUN 或路由器代理没有接管 CFST 流量。测速和订阅同步都需要联网。

测速通常需要数分钟，CFST 整体最多运行 20 分钟，之后还有完整节点复测。网页会显示各阶段进度和已用时间，可随时取消。

## 刷新、断线与完全退出

关闭或刷新网页不会取消后台任务。助手仍在运行时，在同一设备空间和场景填写相同的原始节点、端口、地址类型，点击“继续接收测速结果”即可恢复，无需重新扫描。

网页连续 90 秒读不到进度会结束等待，后台任务继续；测速核心连续 90 秒没有计数进展则会报错。电脑重启或助手退出后，旧任务不能跨进程继续，需重新开始测速。

点击“取消测速”可停止当前任务。完全退出请运行 `完全退出订阅器.cmd`，或在连接 v1.3.7 及更新助手后点击网页“完全退出助手”；独立命令行任务请用 CMD 退出。退出保留配置、节点、身份、结果和订阅，不结束其他 Node、Xray 或代理客户端。

助手连续空闲 30 分钟会自动退出，网页健康检查不会延长空闲时间。

## 更换节点与网络场景

只更新入口或备注时沿用订阅地址。更换原始节点并确认发布后会生成新地址，旧地址失效，请替换客户端中的地址。Cloudflare KV 的更新和旧地址失效可能需要传播时间。

`home`、`work`、`hotspot` 和自定义场景分别保存结果与历史。切换会清空当前草稿，切换前请发布或导出配置备份。不同设备的数据分别保存；换浏览器后找不到原结果，可从本机“打开订阅器”重新绑定。

面板可保存节点模板、导出配置备份，并从最近 3 版历史中选择回滚。保存模板不改动已发布节点，恢复备份只回填草稿，回滚需再次确认。

## 六个入口

| 入口 | 用途 |
| --- | --- |
| `启用网页测速.cmd` | 首次使用或移动目录后，注册网页唤起入口 |
| `打开订阅器.cmd` | 启动助手，绑定本机空间并打开网页 |
| `填写原始节点.cmd` | 保存命令行流程使用的本机节点 |
| `开始测速.cmd` | 自动测速、复测，满足条件后上传固定订阅 |
| `复测节点.cmd` | 只生成完整链路复测报告，不自动发布 |
| `完全退出订阅器.cmd` | 取消任务，结束当前目录所属的助手和测速进程 |

网页输入不会写入本机“我的节点.txt”。命令行入口遇到空节点会打开填写窗口，保存后继续，取消则退出。成功上传的订阅地址位于 `运行结果/v2rayN订阅地址.private.txt`。

## 升级并保留原数据

1. 将新包解压到另一个目录，等待旧任务结束并关闭网页。
2. 用新包脚本退出经过身份与路径核对的旧空闲助手。在 PowerShell 中运行，将下列目录换成实际路径：

   ```powershell
   & '新包目录\程序\运行时\node.exe' '新包目录\程序\tools\local-speedtest.mjs' --stop --config '旧目录\本机配置.json'
   ```

3. 助手仍在测速时会拒绝退出，先等待或取消任务。
4. 把旧“程序”目录和**全部六个 CMD** 移到可恢复归档，再复制新包的“程序”目录与全部 CMD。
5. 保留旧目录的 `本机配置.json`、`我的节点.txt`、`设备身份.private.json`、`运行结果/` 及其中的发布事务，**不要用新包的空白配置覆盖它们**。
6. 运行旧目录中的新版 `打开订阅器.cmd`，继续使用原设备空间和场景。

## 上传中断或本地保存失败

命令行上传前会暂存新结果并备份旧文件，收到成功响应后才替换稳定结果。上传响应丢失时线上可能已经更新；本地与远程无法一起原子提交，程序会提示发布事务目录并暂停再次自动发布。

在原便携目录运行，将事务路径替换成提示的实际目录：

```powershell
.\程序\运行时\node.exe .\程序\tools\cfst-sync.mjs --config .\本机配置.json --recover-local '.\运行结果\发布事务-时间-编号.private'
```

该命令只读取线上状态，匹配后恢复本地结果，不重复上传。其他场景加 `--profile work` 或 `--profile hotspot`。请保留事务及备份；持续磁盘故障或进程突然退出时，自动回退不一定完成。网页发布未收到确认时，先刷新订阅状态核对，避免重复提交。

## 数据与分享

本机身份由 Windows DPAPI 加密保存。网页确认发布后，节点与订阅内容保存在当前设备的 Cloudflare KV 空间；每个设备空间分别保存自己的节点、入口、模板和历史。

**订阅链接自身带有读取权限。** 节点文件、配置备份、复测任务、设备身份和运行结果不要公开。继续分享工具时发送原始干净 ZIP，不要重新压缩使用过的目录。换电脑请重新解压并建立新身份。

## 常见问题

| 问题 | 处理方式 |
| --- | --- |
| 助手未连接 | 允许访问本地网络，唤起助手后点击“检查连接”；首次使用先运行“启用网页测速” |
| 找不到 Node、Xray 或网段文件 | 重新完整解压，入口和整个“程序”目录需保留在一起 |
| 节点无效或测速数量不足 | 确认原节点可连接、使用 WebSocket + TLS 且没有 flow，并检查网络和 TUN 接管情况 |
| 换浏览器后没有原结果 | 从原目录运行“打开订阅器”，并核对网络场景名称 |
| 已发布但客户端仍显示旧结果 | 刷新客户端订阅；传播延迟时稍后重试，更换原节点后需使用新地址 |

完整操作与参数说明见 [PDF 使用指南](使用指南.pdf)。

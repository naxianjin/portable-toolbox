# Cloudflare 优选 IP 订阅器 · 网页测速助手

在网页输入自己的 VLESS + WebSocket + TLS 节点，点击按钮，由本机内置 CFST 测量连接延迟和下载速度，再用 Xray 复测完整连接。成功后自动回填 15 个优选 IP，前 10 条均通过复测；核对发布后即可导入客户端。同一原节点重新测速沿用订阅地址，更换原节点会生成新地址。

支持 Windows 10 / 11 64 位，推荐当前版本的 Edge 或 Chrome。包内已有 Node、CFST、官方 IP 列表、Xray 以及必要依赖；不需要安装开发环境、管理员权限或 Cloudflare 账号。

## 第一次使用

1. **完整解压**程序包到可写文件夹，保留“程序”目录；不要直接在压缩软件中运行入口。
2. 首次双击 **启用网页测速.cmd** 一次。以后直接访问网页，点击 **唤起测速助手** 并允许浏览器打开本机应用。也可继续双击 **打开订阅器.cmd**，自动注册入口并打开本机空间。
3. 在网页 **原始节点** 中粘贴自己能连接的 `vless://` 分享链接，点击 **一键测速并填入**。浏览器首次请求访问本地网络时，允许该请求。
4. 等待网页显示测速与完整连接复测进度。成功后自动填入 15 个入口，通过者按下载速度优先排列，前 10 条供订阅使用。
5. 点击 **预览并更新订阅**，核对并确认发布。到 **订阅结果** 复制对应客户端的地址或扫码导入。

可先点击“检查连接”，无需输入节点，即可查看助手版本与测速文件是否齐全。测速时显示三个阶段、实际进度和已用时间，完整扫描与下载通常需要数分钟。

无需打开测速窗口、复制 IP 或手动导入 CSV。测速只回填草稿，确认发布后才更新 Cloudflare KV。首次启用后，即使电脑重启，也可从网页唤起助手，无需再运行 CMD。助手运行期间，同一浏览器刷新或新开标签会自动重连。浏览器仍需本机助手执行 TCP、指定 IP 下载和完整节点复测；移动便携目录后请重新启用网页入口。

断线不会取消后台测速。刷新或重连后，填写该任务相同的原始节点、端口和地址类型，点击“继续接收测速结果”即可恢复。状态读取或发布预览遇到网络中断时，新版会尝试本机通道；写入失败不会自动重复提交。

## 升级并保留已有设备数据

等测速结束并关闭网页。旧助手仍可能占用 Node，先在 PowerShell 使用新包的运行时和脚本退出经过身份核对的空闲助手：

```powershell
& '新包目录\程序\运行时\node.exe' '新包目录\程序\tools\local-speedtest.mjs' --stop --config '旧目录\本机配置.json'
```

将“新包目录”和“旧目录”换成实际路径。助手仍在测速时会拒绝退出。退出成功后，把旧“程序”目录和全部 CMD 移到可恢复归档，再复制新包的“程序”目录和全部 CMD，运行旧目录中的新版“打开订阅器.cmd”。保留旧根目录的配置、节点、身份、运行结果和发布事务，不要用新包的空白配置覆盖它们。新助手重复启动时复用同一端口；新网页遇到旧助手会明确提示升级。

v1.3.0 修复了旧版 CMD 换行格式导致的命令截断。本机节点为空时，“开始测速.cmd”会打开填写窗口，保存后继续，取消则退出。

v1.3.1 修复进度读取不完整、刷新后连接丢失，以及读不到进度时自动取消任务的问题。升级后需要启动一次新版助手。

v1.3.2 固定测试 30 个低延迟候选，再从中筛选 15 个达到速度门槛的入口。默认下载阶段最长约 5 分钟，不会为了凑够达标入口而一直遍历全部候选；界面会说明 0/30 或 0/15 的含义。

v1.3.3 在本轮完整复测通过不足 10 个时，临时重新测速上次入口，只取补足发布门槛所需的最快入口。最终 15 条优先排列本轮新通过入口，前 10 条均通过完整复测。

v1.3.4 让网页测速与“开始测速.cmd”共用同一套旧入口补位规则，并按 home、work、hotspot 等网络场景分别读取上次结果。重复、异端口、零速、测速失败或完整复测失败的旧入口不会补位；失败或取消时不覆盖原结果和线上订阅。便携包不再包含 `node_modules` 目录，固定版本的必要运行库改放在包内 vendor 目录。

v1.3.5 修复 IPv6 等价文本重复计数、旧入口绕过最低速度和 CLI 复测结束时取消仍可能上传的问题。上传前先暂存与备份本地结果；替换失败会回退已替换文件。上传响应丢失时线上可能已更新，终端会提示发布事务目录，并暂停再次自动发布。按 PDF 的 `--recover-local` 命令读取线上当前版本，与暂存匹配后恢复本地结果，不重复上传。本地文件和远程 KV 无法一起原子提交；磁盘持续故障或进程突然退出时需保留事务目录继续恢复。事务内容含节点与订阅地址，不得分享。

v1.3.6 修复 Windows 无换行输出导致延迟和下载进度停在第一帧的问题，增加下载进度条、当前候选及等待秒数；连续 90 秒无计数进展会明确报错并保留旧结果。新增网页唤起助手，首次启用后无需每次运行 CMD。改进手工入口的网络重试与备用通道，写入失败仍不重复提交。101 项测试和本地 Edge 验证通过；尚未在报告问题的用户电脑上复测。

## 更换原始节点与订阅地址

只更新优选 IP 或备注时沿用地址。更换原始节点后，发布预览会提示生成新地址；确认后请替换客户端中的订阅地址，旧地址会失效。若已在旧版换过原节点却仍沿用旧地址，可勾选“生成新订阅地址（旧地址将失效）”后确认发布。Cloudflare KV 的内容更新与旧地址失效可能需要 60 秒或更久。

## 测速规则

- 默认选择无探测丢包、连接延迟不超过 200 ms、下载速度至少 0.1 MB/s 的 15 个 IP。
- Xray 对每个入口发起 3 次完整 HTTPS 请求；本轮通过不足 10 个时，会重新测速上次入口并选择最快的合格入口补位。
- 最终顺序为本轮新通过入口、旧入口补位、本轮其他候选，前 10 条均通过完整复测。
- CFST 最长运行 20 分钟，之后还有完整节点复测。可以取消；失败、取消或数量不足时保留已有入口和订阅。
- CFST 连接延迟、CFST 下载速度和完整 HTTPS 请求耗时是不同指标。实际代理下载速度可在客户端另测。

测速前确认 TUN 或路由器代理没有接管 CFST 流量，否则结果可能反映代理线路。工具使用当前电脑的网络，测速与同步需要联网。

## 节点与设备数据

程序包不提供 VPS 或原始节点，也不包含作者的真实节点。每台电脑建立自己的设备空间；节点、IP、模板、历史和订阅地址分别保存。

网页测速不将原始节点写入本机“我的节点.txt”。确认发布后，节点模板和订阅内容保存到当前设备的 Cloudflare KV 空间。本机长期身份由 Windows DPAPI 加密保存，网页不需要手动填写密钥。

订阅链接本身带有读取权限。继续分享工具时，发送这里下载的干净 ZIP；已经使用过的目录含有设备身份和运行结果，不要重新压缩公开上传。

## 其他入口与常见问题

| 入口 | 用途 |
| --- | --- |
| 启用网页测速.cmd | 首次注册网页唤起入口，无需管理员权限 |
| 打开订阅器.cmd | 推荐入口：自动绑定设备、启动助手并进入网页 |
| 填写原始节点.cmd | 为原命令行流程保存本机节点文件 |
| 开始测速.cmd | 原命令行自动测速、复测和上传流程 |
| 复测节点.cmd | 仅生成完整链路复测报告 |

**网页提示助手未连接**：允许浏览器访问本地网络并点击“检查连接”。助手已运行时可自动重连；电脑重启或助手退出后，可点击网页“唤起测速助手”；首次使用需先启用一次网页入口。

**找不到 Node 或 Xray**：检查是否完整解压，入口和整个“程序”目录应保留在一起。

**测速不够 15 个或新旧入口合计仍不足 10 个**：检查原始节点是否可用、网络状态及 CFST 是否被其他代理接管，再重新测速。

**客户端连接**：v2rayN / v2rayNG 使用 Raw；支持 VLESS 的 Clash / Mihomo 使用 Clash 格式；Shadowrocket 使用对应入口。实际使用节点仍需要自己的代理客户端。纯 VLESS 不提供 Surge 导出。
